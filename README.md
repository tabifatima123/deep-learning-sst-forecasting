# Deep Learning for Time Series Forecasting: Case Study on Sea Surface Temperature (SST)


This repository contains a deep learning workflow for **time series forecasting** using **Sea Surface Temperature (SST)** as a case study. It includes dataset access links, preprocessing, model training, and evaluation inside a Jupyter Notebook.

---

## Project Objectives

- Build a reproducible pipeline for SST time series forecasting  
- Apply deep learning models to learn temporal patterns  
- Evaluate forecasting performance using standard metrics  
- Present results clearly for academic submission
